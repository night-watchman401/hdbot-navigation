# 验证记录 — 2026-10-18

运行环境：ROS 2 Jazzy、slam_toolbox 2.8.5、GTSAM 4.3.0 开发版本，提交哈希为 `71a25ca36c084cbad1f872e812d6d97fbadfdb05`，使用的 GTSAM 构建目录为 `../../../gtsam/build`。

* 使用 `-DGTSAM_DIR=<GTSAM构建目录>` 执行 `colcon build --packages-up-to hdbot_gtsam_backend`：**通过**。
* 对官方 `DopplerFactorArm` 头文件、局部导航坐标系版本的构造函数以及共享库符号进行编译/链接探测：**通过**。
* 执行 `colcon test --packages-select hdbot_gtsam_backend`：共 **14 项测试**，失败、错误和跳过均为 **0**（其中模型/因子图测试 10 项，求解器/ROS 测试 3 项，建图器生命周期测试 1 项）。
* 对已安装可执行文件和库的依赖进行解析检查：**未发现缺失的库**。
* 软件包 XML、插件注册 XML、启动文件语法和 YAML 解析检查：**通过**。

模型测试的检查项目包括：

* 通过有限差分验证多普勒适配器的全部四个雅可比矩阵；
* 验证两个车轮耦合雅可比矩阵和两个相对位姿雅可比矩阵；
* 检查角速度为零、杆臂为零和仅有竖直杆臂时的退化情况；
* 检查自由速度变量对偏航角变化的补偿现象；
* 检查禁用 GNSS 时原始位姿图的行为，以及回环边是否保留；
* 检查乱序历元、重复历元和跨时间间隔的钟差状态分段；
* 检查重复求解时的规范自由度（gauge）稳定性、不连通分量以及重置操作。

在一个**包含车轮/无侧滑耦合约束**、且不含噪声的合成示例中，初始航向误差由 **0.35 rad** 降至 **9.47e-6 rad**；原始多普勒观测的均方根误差（RMS）为 **2.58e-6 m/s**。这些数值用于验证代码实现，**不代表真实场景中的定位精度，也不证明多普勒能够独立观测姿态**。

ROS 测试通过真实的进程内订阅接口，发布带时间戳的 IMU、车轮里程计和卫星原始观测消息。求解器添加了 **12 个多普勒因子**；删除一个节点后，保留 **6 个多普勒因子**以及预期仍应存在的位姿约束边。测试还覆盖了 Pluginlib 插件加载，以及 Karto 的 `Clear`/`Reset` 语义。

建图器测试直接使用新的求解器，对实际的生命周期节点依次执行配置、激活、停用、清理和重新配置操作。

另外还进行了独立的 `ros2 launch` 冒烟测试：成功启动已安装的可执行文件、加载 GTSAM 插件，并进入配置阶段。但当前执行沙箱不允许创建 DDS UDP 套接字（错误信息为 `Operation not permitted`），因此**尚未验证跨进程自动激活，也未完成完整的 Gazebo/真实 GNSS 建图运行测试**。该启动测试在超时后被终止。

当前没有真实 GNSS 数据集或接收机驱动程序。评估传感器性能前，需要先完成地理坐标对齐配置并提供真实观测数据。天线模型和 URDF 的修改留给用户自行完成。
